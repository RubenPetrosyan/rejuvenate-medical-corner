# Rejuvenate Medical Corner

Official website for Rejuvenate Medical Corner, an aesthetic medicine and dental clinic in Yerevan, Armenia (Paruyr Sevak 9/95, Yerevan 0014).

- Trilingual: Armenian (default), Russian, English
- 13 services, each with its own page
- Booking via WhatsApp
- Fully static site: this repository contains a single self-contained `index.html` (all images and styles inlined). No build step is required.

## Deploy

Import this repository into Vercel with Framework Preset "Other", no build command, and no output directory override. The site serves from `index.html` at the root.
